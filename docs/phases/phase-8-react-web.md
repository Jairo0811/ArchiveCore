# Phase 8 — React Web Application

Implemented:

- React + TypeScript + Vite SPA.
- TanStack Query server-state layer.
- React Router navigation.
- JWT login experience.
- Session-scoped authentication state.
- Responsive ArchiveCore enterprise shell.
- Dashboard backed by API metrics.
- Record search/list view.
- Role-aware audit navigation.
- Documents and Audit module entry points for local validation.
- API base URL configurable through `VITE_API_BASE_URL`.

The visual system follows the ArchiveCore identity: dark navy surfaces with cyan/teal security and data-management accents.
